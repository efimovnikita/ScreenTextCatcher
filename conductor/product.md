# Initial Concept

Утилита для Windows, которая висит в системном трее и позволяет по нажатию глобальной горячей клавиши активировать режим захвата экрана:
- При активации экран затемняется на 50%.
- Пользователь выделяет рамкой прямоугольную область экрана.
- Вырезанное изображение отправляется в Mistral OCR Cloud Service.
- Распознанный текст автоматически копируется в буфер обмена Windows.
- В окне настроек:
  - Поле для ввода API ключа Mistral.
  - Поля для настройки и тестирования прокси-сервера (через который утилита работает с Mistral API).

# Product Guide — ScreenTextCatcher

## Обзор продукта
ScreenTextCatcher — легковесная утилита для Windows, работающая в системном трее, поддерживающая два режима работы: мгновенное оптическое распознавание текста (OCR) с любого участка экрана через Mistral OCR, а также сохранение скриншотов в папку с автоматической аккумуляцией путей к файлам в буфере обмена.

## Ключевые возможности
1. **Захват экрана по горячей клавише**:
   - Глобальная горячая клавиша по умолчанию: `Win+Shift+X` (с возможностью переназначения в настройках).
   - При нажатии экран затемняется на 50% (overlay-слой).
   - Пользователь интерактивно выделяет прямоугольную область рамкой.
   - Отмена захвата по нажатию `Esc` или клику правой кнопкой мыши.

2. **Распознавание текста через Mistral OCR**:
   - Выделенный фрагмент экрана отправляется в Mistral OCR Cloud Service.
   - Поддержка работы через настроенный прокси-сервер (HTTP/HTTPS/SOCKS5).
   - Индикация статуса: иконка в трее отображает текущее состояние (Idle, Processing, Error) с помощью предкомпилированных контрастных иконок в фирменном стиле Mistral AI.
   - Распознанный текст автоматически копируется в буфер обмена Windows.

3. **Обратная связь**:
   - Тихий режим: ненавязчивый звуковой сигнал / индикация в трее об успехе, текст сразу готов к вставке (`Ctrl+V`).

4. **История распознаваний**:
   - Локальное сохранение последних 100 распознанных фрагментов.
   - Быстрый доступ к истории через меню системного трея (повторный клик по элементу копирует его в буфер).

5. **Окно настроек**:
   - Ввод и защищённое сохранение Mistral API Key.
   - Поля настройки параметров прокси-сервера.
   - Кнопка тестирования (Test / Ping) соединения с прокси и проверки валидности Mistral API ключа.
   - Настройка комбинации горячей клавиши.

6. **Автозапуск при старте Windows**:
   - Опция включения/отключения автозапуска при входе в систему через ярлык в папке Startup.
   - Доступно для настройки как в окне настроек, так и напрямую из контекстного меню системного трея.

7. **Режим сохранения скриншотов (Screenshot Mode)**:
   - Быстрое переключение между режимами OCR и скриншотов в трее, на дашборде и в настройках.
   - Встроенный режим аннотирования: нанесение контрастных прямоугольных рамок и стрелок со сплошным треугольным наконечником (#FF1744, 3px) прямо на оверлее.
   - Мгновенная «заморозка» экрана при открытии, плавающая панель инструментов с защитой от вылета за границы экрана, отмена действий (Ctrl+Z), сохранение по Enter и отмена по Esc.
   - Кнопка «📋 Копировать» на панели инструментов для мгновенного сохранения файла на диск и копирования графического изображения напрямую в буфер обмена Windows (готово для вставки Ctrl+V в мессенджеры и редакторы).
   - Сохранение выделенного фрагмента экрана в PNG (`Screenshot_yyyyMMdd_HHmmss.png`) в целевую папку (по умолчанию `%USERPROFILE%\Pictures\ScreenTextCatcher`).
   - Автоматическая аккумуляция полных путей к сохраненным файлам в буфере обмена с настраиваемым разделителем (перенос строки `\r\n` или пробел).

8. **Фирменный бренд-комплект иконок**:
   - Официальная мастер-иконка исполняемого файла (.exe) и окон приложения (видоискатель с литерой «T» в градиенте Mistral AI).
   - Набор иконок системного трея со всеми DPI-слоями Windows для состояний ожидания, отправки запроса и ошибок.

## Целевая аудитория
Пользователи Windows, которым требуется быстро копировать невыделяемый текст с изображений, презентаций, видео, PDF-сканов и удалённых сессий, а также быстро сохранять серии скриншотов с получением путей к файлам в буфере обмена.
