# Specification: Режим аннотирования скриншотов (Screenshot Annotation Mode)

## 1. Overview
Добавление легковесного in-place режима аннотирования поверх выделенной области экрана при создании скриншотов (`AppMode.Screenshot`). В режиме аннотирования пользователь может наносить прямоугольные рамки и стрелки фиксированного фирменного стиля перед сохранением снимка экрана. Режим оптического распознавания текста (`AppMode.Ocr`) остаётся изолированным и функционирует без изменений.

---

## 2. Functional Requirements

### 2.1. Инициализация и захват экрана
- При вызове захвата экрана в режиме скриншота экран мгновенно «замораживается» (сохраняется полноэкранный растровый снимок), исключая смещение динамического контента во время разметки.
- Оверлей открывается с замороженным фоновым изображением под полупрозрачной маской.
- Пользователь протягивает прямоугольную рамку выделения (ЛКМ). Если размер выделения < 8×8 пикселей, захват сбрасывается как случайный клик.

### 2.2. Переход в режим аннотирования и плавающая панель инструментов
- При отпускании ЛКМ область захвата фиксируется, и под нижней границей выделения (или над верхней, если выделение вплотную к нижнему краю экрана) появляется компактная плавающая панель инструментов.
- Панель автоматически позиционируется в пределах видимой области экрана / монитора.
- По умолчанию при появлении панели **ни один инструмент рисования не активен** (обычный курсор-стрелка, клики внутри области игнорируются).
- Состав панели инструментов:
  - `[▢ Рамка]` — инструмент рисования прямоугольной рамки;
  - `[➔ Стрелка]` — инструмент рисования стрелки;
  - Разделитель;
  - `[↩ Отмена действия]` — Undo последнего элемента (активна только при наличии нарисованных фигур);
  - Разделитель;
  - `[✓ Готово]` — сохранение скриншота;
  - `[✕ Отмена]` — отмена захвата без сохранения.

### 2.3. Инструменты и визуальный стиль
- **Цветовая схема и толщина**:
  - Фиксированный высококонтрастный ярко-красный цвет: `#FF1744`.
  - Фиксированная толщина линий: `3px`.
  - Отсутствуют меню выбора цвета и толщины.
- **Прямоугольная рамка (Rectangle)**:
  - Контурный прямоугольник без заливки (`Fill = Transparent`, `Stroke = #FF1744`, `StrokeThickness = 3`).
- **Стрелка (Arrow)**:
  - Направлена от точки нажатия ЛКМ к точке отпускания ЛКМ (указывает на цель).
  - Тело стрелки — линия (`Stroke = #FF1744`, `StrokeThickness = 3`).
  - Наконечник — сплошной залитый треугольник (`Fill = #FF1744`, угол раствора $\approx 25^\circ\dots 30^\circ$, длина $14\dots 16\text{ px}$).
- **Область рисования**:
  - Фигуры размещаются на канвасе внутри выделенной области с `ClipToBounds = True`.
  - Начальные и конечные координаты фигур не ограничиваются искусственным clamp — отсечение выполняется визуально границами канваса.

### 2.4. Поведение манипуляторов и горячие клавиши
- **«Залипание» инструмента**: после нанесения фигуры выбранный инструмент остаётся активным, позволяя рисовать несколько рамок или стрелок подряд без повторного клика.
- **Переключение инструментов**: осуществляется **только кликом мыши** по кнопкам панели (без глобальных хоткеев переключения).
- **Правая кнопка мыши (ПКМ)**: в фазе аннотирования полностью неактивна (не сбрасывает инструмент и не закрывает окно).
- **Горячие клавиши**:
  - `Enter`: сохранение скриншота (эквивалент кнопки `[✓ Готово]`). Можно нажать сразу после выделения для сохранения без аннотаций.
  - `Ctrl+Z`: отмена последнего нарисованного элемента (эквивалент кнопки `[↩ Отмена действия]`).
  - `Esc`: отмена захвата и закрытие оверлея без сохранения файлов (эквивалент кнопки `[✕ Отмена]`).

### 2.5. Экспорт и интеграция
- При нажатии `Enter` или клике `[✓ Готово]`:
  - Выделенный регион вместе с канвасом аннотаций рендерится в массив байтов PNG через `RenderTargetBitmap` с сохранением DPI-масштабирования экрана.
  - Готовый массив `pngBytes` передается в `MainWindow` и сохраняется через `ScreenshotService` в целевую папку.
  - Путь к сохранённому файлу аккумулируется в буфере обмена Windows в соответствии с текущими настройками разделителя.
  - Оверлей закрывается.

### 2.6. Локализация (i18n)
- Добавление ключей в `LocalizationManager` для русской (`ru`) и английской (`en`) локализаций:
  - `Loc_AnnotateToolbarRect` ("Рамка" / "Rectangle")
  - `Loc_AnnotateToolbarArrow` ("Стрелка" / "Arrow")
  - `Loc_AnnotateToolbarUndo` ("Отменить действие (Ctrl+Z)" / "Undo (Ctrl+Z)")
  - `Loc_AnnotateToolbarDone` ("Сохранить (Enter)" / "Save (Enter)")
  - `Loc_AnnotateToolbarCancel` ("Отмена (Esc)" / "Cancel (Esc)")

### 2.7. Изоляция режима OCR
- В режиме `AppMode.Ocr` логика остаётся неизменной: при отпускании ЛКМ оверлей немедленно закрывается и передает координаты прямоугольника для распознавания.

## 3. Non-Functional Requirements
- **Обработка в памяти**: Все промежуточные растровые и векторные операции производятся исключительно в RAM.
- **Поддержка DPI и мониторов**: Корректное масштабирование панели, координат и экспорта при любых системных масштабах (100%, 125%, 150%, 200%) и на многомониторных конфигурациях.
- **Производительность**: Мгновенный интерактивный отклик при рисовании без лагов и задержек UI-потока.

## 4. Acceptance Criteria
1. [x] В режиме скриншота после выделения области появляется плавающая панель с кнопками: Рамка, Стрелка, Отмена действия, Готово, Отмена.
2. [x] Нажатие `Enter` сразу после выделения сохраняет чистый скриншот без аннотаций.
3. [x] Инструмент «Рамка» рисует красный прямоугольник 3px `#FF1744` без заливки.
4. [x] Инструмент «Стрелка» рисует красную линию со сплошным залитым треугольным наконечником.
5. [x] Повторные фигуры рисуются без повторного выбора инструмента; ПКМ не сбрасывает инструмент.
6. [x] Кнопка Undo и `Ctrl+Z` последовательно удаляют нарисованные фигуры; кнопка блокируется, когда стек пуст.
7. [x] `Esc` и кнопка Отмена закрывают оверлей без сохранения файла.
8. [x] Экспортированный PNG файл содержит выделенный фрагмент экрана с точно наложенными векторными аннотациями в высоком качестве с учетом DPI.
9. [x] В режиме OCR оверлей работает мгновенно и без панели аннотаций, отправляя фрагмент в Mistral OCR.
10. [x] Модульные тесты геометрии, стека аннотаций и сервисов успешно проходят (`dotnet test`).

---

## 5. Out of Scope
- Меню выбора произвольных цветов и толщины линий.
- Дополнительные инструменты рисования (свободная кисть, маркер/хайлайтер, текст, размытие, эллипсы).
- Перемещение или масштабирование уже нарисованных фигур.
- Горячие клавиши переключения между инструментами рисования.
