# Track Specification — Опция автозапуска приложения при старте Windows

## 1. Обзор
Цель трека — реализовать возможность включения и отключения автозапуска ScreenTextCatcher при старте Windows через создание и удаление ярлыка в папке автозагрузки пользователя (`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`), с управлением из окна настроек и контекстного меню системного трея. Завершающим этапом является выпуск новой версии (v1.1.0) с автоматической публикацией дистрибутива на GitHub Releases.

## 2. Архитектура и структура решения
- **Core / Сервисы (`ScreenTextCatcher.Core`)**:
  - `AppSettings.cs`: добавление свойства `public bool AutoStart { get; set; } = false`.
  - `IAutoStartService.cs` & `AutoStartService.cs`:
    - `bool IsAutoStartEnabled()`: проверка наличия ярлыка в папке Startup и соответствия целевого пути текущему exe-файлу.
    - `bool EnableAutoStart()`: создание/обновление ярлыка `ScreenTextCatcher.lnk` в каталоге Startup с помощью COM `IShellLinkW` / `IPersistFile` без сторонних зависимостей.
    - `bool DisableAutoStart()`: удаление ярлыка из каталога Startup.
    - `bool SetAutoStart(bool enable)`: установка статуса и логирование результата.
  - `LocalizationManager.cs`: новые строковые ключи для русского и английского языков (`Loc_AutoStart`, `Loc_AutoStartHelp`, `Loc_TrayAutoStart`).
- **UI / Презентация (`ScreenTextCatcher`)**:
  - `Views/SettingsWindow.xaml` и `SettingsWindow.xaml.cs`:
    - Чекбокс `ChkAutoStart` ("Запускать при старте Windows") в секции параметров интерфейса/системы.
    - Сохранение и синхронизация состояния с `AutoStartService` и `AppSettings`.
  - `Tray/TrayIconManager.cs`:
    - Пункт контекстного меню с отметкой выбора (Checkable MenuItem) для быстрого переключения автозапуска прямо из трея.
    - Автоматическая синхронизация галочки при изменении настроек.
  - `App.xaml.cs`:
    - Проверка и синхронизация при старте приложения: если в `AppSettings.AutoStart == true`, проверка актуальности ярлыка (например, если exe был перемещен).
    - Запуск приложения продолжается скрытно в системный трей (без открытия окон).
- **Тесты (`ScreenTextCatcher.Tests`)**:
  - `AutoStartServiceTests.cs`: модульные тесты логики сервиса автозапуска с тестовой временной директорией Startup.
- **Релиз и CI/CD (`.github/workflows/release.yml`)**:
  - Создание тега `v1.1.0` и публикация релиза с бинарным архивом `ScreenTextCatcher-win-x64.zip`.

## 3. Критерии приемки (Acceptance Criteria)
1. Пользователь может включить чекбокс автозапуска в `SettingsWindow` и нажать "Сохранить" — ярлык `ScreenTextCatcher.lnk` появляется в папке `Startup`.
2. Пользователь может отключить автозапуск в `SettingsWindow` — ярлык удаляется из `Startup`.
3. Пользователь может включить/отключить автозапуск кликом по пункту контекстного меню трея — состояние мгновенно обновляется и в файловой системе, и в настройках.
4. Значение по умолчанию для новых конфигураций: `AutoStart = false`.
5. Поведение при автозапуске: запуск происходит скрытно в системный трей без всплывающих окон.
6. Ошибки доступа к файловой системе корректно перехватываются, логируются и не вызывают аварийного завершения приложения.
7. Все автоматические тесты проходят успешно (`dotnet test`).
8. После завершения реализации создается git-тег `v1.1.0`, запускается GitHub Actions Release workflow и публикуется релиз с zip-архивом дистрибутива.

## 4. Вне рамок трека (Out of Scope)
- Регистрация в реестре Windows (`HKCU\Run` / `HKLM\Run`).
- Создание задач в Планировщике заданий (Task Scheduler).
- Запуск приложения с повышенными привилегиями администратора (UAC elevation).
