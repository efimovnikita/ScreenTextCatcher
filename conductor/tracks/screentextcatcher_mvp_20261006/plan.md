# Implementation Plan — Создание MVP ScreenTextCatcher

## Phase 1: Инициализация проекта и базовые сервисы ядра

- [ ] Task: Создание структуры решения и проектов .NET 9
    - [ ] Настроить решение ScreenTextCatcher.sln и проекты ScreenTextCatcher.Core, ScreenTextCatcher (WPF), ScreenTextCatcher.Tests
    - [ ] Подключить зависимости (Microsoft.Data.Sqlite, Serilog, System.Drawing.Common, xUnit, Moq, FluentAssertions)
    - [ ] Проверить успешную сборку `dotnet build` и запуск пустых тестов `dotnet test`
- [ ] Task: Реализация сервиса конфигурации (Settings)
    - [ ] Написать модульные тесты для сохранения и загрузки настроек в формате JSON (`ConfigurationServiceTests.cs`)

- [ ] Task: Реализация подсистемы логирования
    - [ ] Написать модульные тесты для логирования и маршрутизации событий в буфер UI
    - [ ] Настроить Serilog с файловой ротацией логов и потоком сообщений для окна просмотра логов
- [ ] Task: Реализация сервиса истории распознаваний (SQLite)
    - [ ] Написать модульные тесты для сохранения, чтения и лимитирования до 100 записей (`HistoryServiceTests.cs`)
    - [ ] Реализовать SQLite хранилище с автоматическим созданием таблицы и удалением записей сверх лимита 100

## Phase 4: Системный трей, глобальный хоткей и интеграция рабочего цикла OCR

- [ ] Task: Модуль перехвата глобальной горячей клавиши
    - [ ] Написать обертку для Win32 API RegisterHotKey / UnregisterHotKey с обработкой оконных сообщений HwndSource
    - [ ] Обеспечить перехват комбинации Win+Shift+X по умолчанию и корректное освобождение при выходе
- [ ] Task: Системный трей и динамическая смена статусов
    - [ ] Реализовать иконку в трее Windows с контекстным меню и индикацией состояния (покой, запрос в Mistral, ошибка)
- [ ] Task: Интеграция полного сквозного цикла OCR
    - [ ] Написать интеграционный тест рабочего цикла: горячая клавиша -> захват фрагмента -> вызов OCR -> буфер обмена
    - [ ] Связать компоненты: оверлей передает координаты в сервис захвата, изображение отправляется в Mistral, результат копируется в Clipboard с тихим звуком
- [ ] Task: Conductor - User Manual Verification 'Системный трей, глобальный хоткей и интеграция рабочего цикла OCR' (Protocol in workflow.md)
