# Track Specification — Внедрение бренд-комплекта иконок приложения и системного трея

## 1. Обзор
Цель трека — создать и интегрировать официальный бренд-комплект векторных и растровых иконок для ScreenTextCatcher, отражающих визуальную метафору OCR через Mistral AI (видоискатель/селектор области с литерой «T» в фирменной янтарно-фиолетовой палитре). Трек включает генерацию концептов с помощью AI, утверждение дизайна, сборку многослойных `.ico` файлов, замену процедурной генерации в `TrayIconManager` на предкомпилированные ресурсы для всех состояний (Idle, Processing, Error), установку иконки приложения для `.exe` и окон интерфейса (`MainWindow`, `SettingsWindow`, `HistoryWindow`, `LogViewerWindow`), а также релиз версии v1.2.2 с публикацией на GitHub.

## 2. Архитектура и структура решения
- **Дизайн и графические ассеты (`src/ScreenTextCatcher/Assets/`)**:
  - Генерация концептов через `image-generator` субагент: видоискатель (crop frame) с угловыми маркерами, стилизованная буква «T» в центре, палитра Mistral AI (градиент от янтарно-оранжевого к глубокому индиго/фиолетовому), контрастные светлые контуры для темной и светлой тем Windows.
  - Согласование превью с пользователем.
  - Подготовка мастер-изображения `app.png` (высокое разрешение с прозрачным фоном).
  - Подготовка цветовых вариаций для трея:
    - `tray_idle.ico`: стандартная фирменная палитра (оранжево-фиолетовая).
    - `tray_busy.ico`: состояние обработки/распознавания (янтарно-золотистая гамма).
    - `tray_error.ico`: состояние ошибки (контрастная ярко-красная гамма).
  - Сборка мастер-иконки `app.ico` с полным набором слоев Windows (16x16, 20x20, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256).
  - Сборка иконок трея `tray_*.ico` со слоями (16x16, 24x24, 32x32).

- **Интеграция в проект и UI (`ScreenTextCatcher`)**:
  - `ScreenTextCatcher.csproj`:
    - Добавление `<ApplicationIcon>Assets\app.ico</ApplicationIcon>`.
    - Включение иконок трея в ресурсы сборки: `<Resource Include="Assets\*.ico" />`.
    - Обновление версии сборки: `<Version>1.2.2</Version>`.
  - Окна приложения (`MainWindow.xaml`, `SettingsWindow.xaml`, `HistoryWindow.xaml`, `LogViewerWindow.xaml`):
    - Указание атрибута `Icon="Assets/app.ico"`.
  - `TrayIconManager.cs`:
    - Удаление устаревшего процедурного метода `CreateSolidColorIcon` и его GDI-вызовов.
    - Реализация метода загрузки иконок из ресурсов приложения (через потоки ресурсов сборки).
    - Корректная обработка жизненного цикла и освобождение дескрипторов `Icon` при вызове `Dispose()`.
    - Бесшовное переключение статусов: Idle -> `tray_idle.ico`, Processing -> `tray_busy.ico`, Error -> `tray_error.ico`.

- **Тестирование и верификация**:
  - Прогон существующих модульных тестов (`dotnet test`).
  - Проверка компиляции и сборки бинарного файла (`dotnet build`).
  - Проверка визуального отображения и переключения состояний трея.

- **Релиз и публикация на GitHub (`.github/workflows/release.yml`)**:
  - Подготовка коммита трека согласно `workflow.md`.
  - Создание git-тега `v1.2.2` и отправка на GitHub.
  - Верификация сборки релиза в GitHub Actions.

## 3. Критерии приемки (Acceptance Criteria)
1. Сгенерированы варианты концептов и утвержден финальный дизайн иконки в фирменном стиле Mistral AI с видоискателем и литерой «T».
2. В каталоге `src/ScreenTextCatcher/Assets/` созданы валидные файлы `app.ico`, `tray_idle.ico`, `tray_busy.ico`, `tray_error.ico` и `app.png`.
3. Исполняемый файл `ScreenTextCatcher.exe` отображает новую мастер-иконку в Проводнике Windows, на панели задач и в диалоге Alt+Tab.
4. Окна приложения (`MainWindow`, `SettingsWindow`, `HistoryWindow`, `LogViewerWindow`) отображают новую иконку в своих заголовках.
5. Иконка в системном трее корректно отображается на экранах с разным масштабом (100%, 125%, 150%) и переключает состояния: Idle, Processing, Error.
6. Процедурная генерация через `CreateSolidColorIcon` удалена, дескрипторы иконок корректно освобождаются.
7. Все существующие модульные тесты успешно проходят (`dotnet test`), сборка без ошибок.
8. Создан git-тег `v1.2.2`, опубликован релиз на GitHub Actions с собранным архивом `ScreenTextCatcher-win-x64.zip`.

## 4. Вне рамок трека (Out of Scope)
- Анимированные иконки трея (GIF / покадровая анимация).
- Динамическая смена пользовательских цветовых тем иконок в настройках.
