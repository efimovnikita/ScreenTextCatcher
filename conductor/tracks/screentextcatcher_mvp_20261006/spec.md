# Track Specification — Создание MVP ScreenTextCatcher

## 1. Обзор
Цель трека — реализовать первый полноценный релиз (MVP) утилиты ScreenTextCatcher на C# / .NET 9 (WPF). Приложение работает в системном трее Windows, реагирует на глобальную горячую клавишу (`Win+Shift+X`), отображает полноэкранный затемняющий оверлей (50% прозрачности) для выделения рамкой нужной области экрана, отправляет вырезанное в RAM изображение в сервис Mistral OCR (через настроенный HTTP/HTTPS/SOCKS5 прокси при необходимости) и копирует распознанный текст в буфер обмена с тихим звуковым подтверждением.

## 3. Детализированные требования

### 3.1 Конфигурация и хранилище
- Файл конфигурации `settings.json` хранится в `%APPDATA%\ScreenTextCatcher\`.
- Структура настроек:
  - `MistralApiKey`: строковый токен.
  - `Proxy`: `Enabled` (bool), `Type` ("Http", "Https", "Socks5"), `Host` (string), `Port` (int), `Username`, `Password`.
  - `Hotkey`: модификаторы (`Win`, `Shift`), клавиша (`X`).
  - `SoundFeedback`: включен/выключен тихий звук.
  - `Language`: "ru" или "en".
- История распознаваний: SQLite база `history.db` в `%APPDATA%\ScreenTextCatcher\`. Хранит до 100 последних записей (`Id`, `Timestamp`, `RecognizedText`). При превышении старые записи удаляются.

### 3.2 Глобальная горячая клавиша
- Использование Win32 API: `RegisterHotKey` и `UnregisterHotKey`.
- По умолчанию: `MOD_WIN | MOD_SHIFT`, клавиша `X`.
- При выходе из приложения или смене хоткея в настройках — корректный `UnregisterHotKey`.

### 3.3 Оверлей выбора области экрана
- Окно WPF без рамок (`WindowStyle="None"`, `AllowsTransparency="True"`, `Topmost="True"`).
- Покрывает все экраны (VirtualScreen: `SystemParameters.VirtualScreenLeft`, `VirtualScreenTop`, `VirtualScreenWidth`, `VirtualScreenHeight`).
- Затемнение фона: черный цвет с прозрачностью 50% (`Opacity="0.5"` или полупрозрачная кисть).
- При зажатии ЛКМ: отрисовка контрастной прямоугольной рамки выделения (ярко-голубой контур с полупрозрачной заливкой).
- При отпускании ЛКМ: расчет прямоугольника, закрытие оверлея, передача координат в сервис захвата.
- Отмена: клавиша `Esc` или клик ПКМ немедленно закрывают оверлей без запуска распознавания.

### 3.4 Захват экрана и кадрирование в RAM
- Захват фрагмента через Win32 `BitBlt` / `Graphics.CopyFromScreen` с учетом DPI.
- Обрезка (crop) в памяти, кодирование в PNG/JPEG внутри `MemoryStream`.
- Категорический запрет на запись файлов изображения на жесткий диск.

### 3.5 Клиент Mistral OCR и сетевой стек
- Использование `HttpClient` с настроенным `SocketsHttpHandler`.
- Если прокси включен — настройка `SocketsHttpHandler.Proxy = new WebProxy(...)` (поддержка HTTP, HTTPS и SOCKS5).
- Вызов endpoint'а Mistral OCR (передача base64 изображения).
- Извлечение распознанного текста из JSON-ответа.
- Обработка исключений: HTTP 401 (неверный ключ), HTTP 429 (лимиты), таймауты подключения к прокси, сетевой сбой. При ошибке — информативное сообщение и запись в лог.

### 3.6 Буфер обмена и оповещение
- Копирование распознанного текста в `System.Windows.Clipboard`.
- Тихий системный звуковой сигнал (например, `SystemSounds.Asterisk.Play()`).

### 3.7 Трей, меню, окно настроек и просмотрщик логов
- Иконка в системном трее с индикацией статуса (обычная, анимированная/подсвеченная во время сетевого запроса, индикация ошибки).
- Контекстное меню трея:
  - Последние записи истории (быстрый клик копирует в буфер).
  - "Открыть историю..." (отдельное окно со всеми 100 записями и поиском).
  - "Настройки..." (диалог конфигурации с кнопкой проверки соединения Test/Ping).
  - "Журнал логов..." (диалог просмотра записей Serilog с подсветкой и кнопками копирования/открытия папки логов).
  - "Выход".

## 4. Критерии приемки (Acceptance Criteria)
1. Решение компилируется без ошибок через `dotnet build`.
2. Набор модульных тестов проходит успешно через `dotnet test` (покрытие ядра >80%).
3. Приложение запускается в фоновом режиме с иконкой в трее.
4. Нажатие `Win+Shift+X` активирует полноэкранный затемняющий оверлей.
5. Выделение рамкой вырезает область экрана в RAM и отправляет запрос в Mistral OCR.
6. Распознанный текст успешно помещается в буфер обмена Windows.
7. В окне настроек работают сохранение API-ключа, настройка прокси и кнопка Test/Ping.
8. Меню логов открывает окно со свежими записями логов.
