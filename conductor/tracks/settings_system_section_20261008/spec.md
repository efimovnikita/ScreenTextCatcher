# Track Specification — Реорганизация настроек: вынос автозапуска в секцию «Система» и релиз v1.2.3

## 1. Обзор
Цель трека — реорганизация структуры окна настроек (`SettingsWindow.xaml`) путём выноса чекбокса «Запускать при старте Windows» (`ChkAutoStart`) из секции «Интерфейс и звук» в отдельную самостоятельную секцию «Система». Это обеспечивает логическое разделение системных параметров ОС от настроек визуализации и звука. Также в рамках трека выпускается патч-релиз v1.2.3 с автоматической сборкой дистрибутива в GitHub Actions.

## 2. Архитектура и структура изменений
- **Словари локализации (`LocalizationManager.cs`)**:
  - Добавление ключа `Loc_SystemGroup`:
    - Русский словарь (`RuDictionary`): `"Система"`
    - Английский словарь (`EnDictionary`): `"System"`
  - Сохранение существующих ключей `Loc_AutoStart`, `Loc_AutoStartHelp`, `Loc_InterfaceAndSoundGroup`.
- **Интерфейс пользователя (`SettingsWindow.xaml`)**:
  - Увеличение высоты окна `Height` с `680` до `740` px (`Width="540"`, `ResizeMode="NoResize"` сохраняется).
  - Секция «Интерфейс и звук»: удаление чекбокса `ChkAutoStart`. В секции остаются только `ChkSound` (звуковой сигнал) и `CmbLanguage` (выбор языка).
  - Новая секция «Система»: добавление карточки `Border` (фон `#252526`, рамка `#3F3F46`, толщина `1`, `CornerRadius="4"`, `Padding="12"`, `Margin="0,0,0,12"`).
  - Заголовок секции: `TextBlock` с текстом `{DynamicResource Loc_SystemGroup}`, `FontWeight="Bold"`, `Foreground="#DCDCAA"`.
  - Элемент управления: `CheckBox x:Name="ChkAutoStart"` с `Content="{DynamicResource Loc_AutoStart}"`, `ToolTip="{DynamicResource Loc_AutoStartHelp}"`, `Foreground="#FFFFFF"`.
  - Порядок расположения: секция «Система» размещается последней карточкой перед кнопками «Сохранить» / «Отмена».
- **Код окна (`SettingsWindow.xaml.cs`)**:
  - Сохранение идентификатора `ChkAutoStart` обеспечивает полную совместимость методов `LoadValues()` и `OnSaveClick()` без правок логики привязки.
- **Модульные тесты (`LocalizationManagerTests.cs`)**:
  - Добавление проверок `Assert.Equal` для ключа `Loc_SystemGroup` для русского и английского языков в тестах `SetLanguage_Ru_ReturnsRussianStrings` и `SetLanguage_En_ReturnsEnglishStrings`.
- **Релиз и публикация**:
  - Обновление версии сборки в файлах проекта до `1.2.3`.
  - Создание git-тега `v1.2.3` и запуск GitHub Actions Release workflow для формирования дистрибутива `ScreenTextCatcher-win-x64.zip`.

## 3. Критерии приёмки (Acceptance Criteria)
1. В окне настроек секция «Интерфейс и звук» содержит только управление звуковым сигналом и переключатель языка.
2. Под секцией «Интерфейс и звук» отображается отдельная карточка «Система» («System» в английской локализации), содержащая чекбокс `ChkAutoStart`.
3. Чекбокс `ChkAutoStart` имеет всплывающую подсказку (`Loc_AutoStartHelp`).
4. Высота окна настроек увеличена до `740` px, все элементы помещаются без искажений интерфейса.
5. Загрузка и сохранение настроек автозапуска продолжают работать корректно (создание и удаление ярлыка в Startup, синхронизация с меню трея).
6. Все модульные тесты проходят успешно (`dotnet test`).
7. Изменения закоммичены с соблюдением `workflow.md`.
8. Создан тег `v1.2.3`, запущен workflow публикации и сформирован релиз.

## 4. Вне рамок трека (Out of Scope)
- Добавление новых параметров в секцию «Система» (например, автообновление или запуск от имени администратора).
- Изменение режима изменения размера окна (`ResizeMode` остаётся `NoResize`).
- Изменение логики взаимодействия с `AutoStartService`.
