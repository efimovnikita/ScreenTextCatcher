# Implementation Plan: Режим создания скриншотов с аккумуляцией путей в буфере обмена

## Phase 1: Модели данных, конфигурация и локализация
- [ ] Task: 1.1 Добавить модель `AppMode` и расширить `AppSettings`
    - [ ] Создать перечисление `AppMode` (`Ocr`, `Screenshot`) в `ScreenTextCatcher.Core.Models`
    - [ ] Добавить свойства `Mode` и `ScreenshotFolder` в `AppSettings` с логикой получения эффективного пути по умолчанию
- [ ] Task: 1.2 Расширить таблицы локализации в `LocalizationManager`
    - [ ] Добавить строки локализации для режимов, папки скриншотов, кнопок обзора/открытия и трея на русском языке (`ru`)
    - [ ] Добавить строки локализации на английском языке (`en`)
- [ ] Task: 1.3 Написать модульные тесты для моделей, настроек и локализации
    - [ ] Добавить тесты сериализации/десериализации новых полей в `ConfigurationServiceTests`
    - [ ] Добавить тесты полноты ключей локализации в `LocalizationTests`
- [ ] Task: Conductor - User Manual Verification 'Phase 1: Модели данных, конфигурация и локализация' (Protocol in workflow.md)

## Phase 2: Бизнес-логика сохранения файлов и аккумуляции буфера обмена (TDD)
- [ ] Task: 2.1 Определить интерфейс `IScreenshotService`
    - [ ] Создать интерфейс `IScreenshotService` в `ScreenTextCatcher.Core.Services` с методами `SaveScreenshot`, `CalculateUpdatedClipboardText`, `SaveAndAccumulateClipboard`
- [ ] Task: 2.2 Разработать модульные тесты для сервиса скриншотов (TDD Red Phase)
    - [ ] Написать тесты для чистой функции `CalculateUpdatedClipboardText` (пустой буфер, валидные файлы, невалидный текст, пути вне целевой папки, несуществующие файлы)
    - [ ] Написать тесты для генерации файлов и разрешения коллизий имён `SaveScreenshot`
- [ ] Task: 2.3 Реализовать `ScreenshotService` (TDD Green Phase)
    - [ ] Реализовать сохранение PNG-байтов на диск с генерацией имен `Screenshot_yyyyMMdd_HHmmss.png` и коллизиями `_1`, `_2`
    - [ ] Реализовать проверку существующих путей и аккумуляцию в буфере обмена
    - [ ] Реализовать интеграционный метод `SaveAndAccumulateClipboard` с защитой буфера обмена
- [ ] Task: Conductor - User Manual Verification 'Phase 2: Бизнес-логика сохранения файлов и аккумуляции буфера обмена' (Protocol in workflow.md)

## Phase 3: Интеграция с пользовательским интерфейсом (UI & Tray)
- [ ] Task: 3.1 Обновить контекстное меню трея (`TrayIconManager`)
    - [ ] Добавить пункты переключения режима (`OCR` / `Скриншоты`) с радио-отметкой (`✓`)
    - [ ] Реализовать динамическое изменение надписи главного пункта захвата («✂ Захват текста экрана» vs «✂ Сделать скриншот»)
    - [ ] Добавить событие `ModeChanged` для синхронизации с открытыми окнами
- [ ] Task: 3.2 Обновить окно настроек (`SettingsWindow`)
    - [ ] Добавить группу выбора режима и настройки папки скриншотов в XAML
    - [ ] Добавить диалог выбора папки (Browse) и кнопку открытия в Проводнике (Open Folder)
    - [ ] Обеспечить привязку, сохранение настроек и локализацию элементов
- [ ] Task: 3.3 Обновить главный экран (`MainWindow`) и пайплайн захвата
    - [ ] Добавить переключатель активного режима и кнопку открытия папки на главный дашборд
    - [ ] Разветвить обработку завершения оверлея в `StartCapture`: при `Screenshot` вызывать `ScreenshotService`, пропуская Mistral OCR и SQLite
    - [ ] Добавить обработку ошибок сохранения с уведомлением в трее и Serilog
