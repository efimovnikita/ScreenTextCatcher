# Specification: Окно просмотра захваченной области («Pin / Закрепить»)

## 1. Overview
В режиме оверлея захвата экрана (`AppMode.Screenshot`) на плавающую панель аннотаций (`AnnotationToolbar`) добавляется компактная кнопка с иконкой **«📌»** (`BtnPin`). При нажатии на неё захваченная область экрана (включая любые нарисованные пользователем аннотации — рамки, стрелки, линии):
1. **Не сохраняется на жесткий диск** (в отличие от кнопки «✓ Сохранить»);
2. **Не копируется в буфер обмена Windows** (в отличие от кнопки «📋 Копировать»);
3. **Не заносится в историю SQLite**;
4. **Отображается в отдельном независимом окне просмотра** (`PinnedImageViewerWindow`), центрируемом на том мониторе, где был выполнен захват.

Это позволяет пользователю зафиксировать визуальную инструкцию, план, фрагмент схемы или чек-лист и переместить окно на любой монитор для непрерывного сопоставления во время работы.

## 2. Architectural Decisions & UI/UX (ADR)
1. **Стиль и тип окна**:
   - Стандартное независимое окно Windows (`SingleBorderWindow`, `ResizeMode="CanResize"`).
   - Классический заголовок Windows, системные кнопки (Свернуть / Развернуть / Закрыть), стандартная рамка изменения размеров.
   - Иконка приложения `/Assets/app.ico`.
2. **Z-Order / Уровень окна**:
   - Обычный уровень (`Topmost = false`), окно не перекрывает принудительно другие программы, свободно перемещается между мониторами.
3. **Мультиоконность и каскадирование**:
   - Поддерживается открытие произвольного количества независимых окон просмотра.
   - Базовая позиция: центр рабочей области (`WorkingArea`) монитора, где происходил захват.
   - При наличии уже открытых окон закрепления на том же мониторе применяется каскадное смещение (+24 px по X и Y).
4. **Панель задач Windows**:
   - `ShowInTaskbar = true`: окно отображается в Taskbar с иконкой приложения и доступно по `Alt+Tab`.
5. **Кнопка на панели аннотаций**:
   - Компактная кнопка `BtnPin` с иконкой `📌`, стиль `ToolbarButtonStyle`, `Margin="2,0,2,0"`.
   - Размещается непосредственно перед кнопкой копирования: `[BtnPin] [BtnCopyImage] [BtnDone]`.
   - Тултип с локализованным текстом через `{DynamicResource Loc_AnnotateToolbarPinTooltip}`.
6. **Отображение изображения и масштабирование**:
   - Масштаб 1:1 (`Stretch="None"`, `SnapsToDevicePixels="True"`).
   - Обертка `ScrollViewer` с автоматическими полосами прокрутки (`ScrollBarVisibility="Auto"`).
   - Темный фон контейнера `#212121` для контрастного отображения любых фрагментов (включая светлые и с прозрачностью).
7. **Поведение и горячие клавиши внутри окна**:
   - Стандартное поведение окон Windows (закрытие только по кнопке «Закрыть» или `Alt+F4`, клавиша `Esc` не закрывает окно принудительно).
   - Без контекстного меню.
8. **Заголовок окна**:
   - Формат: `ScreenTextCatcher — Просмотр ({W} × {H})` (локализовано через `Loc_PinnedViewerTitle`).
9. **Звуковое оповещение**:
   - Тихий спавн (без воспроизведения системных звуков).
10. **Хранение данных**:
    - Исключительно оперативная память (RAM). Экспорт через `AnnotationExportHelper` в PNG `byte[]`, загрузка в `BitmapSource` с `BitmapCacheOption.OnLoad`.

## 3. Functional Requirements

### 3.1. Локализация (`LocalizationManager`)
- Ключ `Loc_AnnotateToolbarPinTooltip`:
  - RU: `"Закрепить на экране (окно просмотра)"`
  - EN: `"Pin on screen (view window)"`
- Ключ `Loc_PinnedViewerTitle`:
  - RU: `"ScreenTextCatcher — Просмотр ({0} × {1})"`
  - EN: `"ScreenTextCatcher — View ({0} × {1})"`

### 3.2. Разметка и логика оверлея (`OverlayWindow`)
- Добавление кнопки `BtnPin` в `AnnotationToolbar` перед `BtnCopyImage`.
- Объявление публичного события `public event Action<byte[], Rect>? PinRequested;`.
- Обработчик `OnPinClick`:
  - Завершение рисования текущей аннотации (если активно).
  - Композитный рендеринг изображения и векторных аннотаций в PNG `byte[]` через `AnnotationExportHelper.CompositeAndRenderToPng`.
  - Закрытие оверлея (`Close()`).
  - Вызов события `PinRequested?.Invoke(pngBytes, _selectedAreaRect)`.

### 3.3. Новое окно `PinnedImageViewerWindow`
- Разметка `PinnedImageViewerWindow.xaml`:
  - Окно со стилем `SingleBorderWindow`, `ResizeMode="CanResize"`, темным фоном `#212121`, иконкой `/Assets/app.ico`.
  - Внутри: `ScrollViewer` с автоматическими полосами прокрутки и элемент `Image x:Name="ViewerImage"` со `Stretch="None"`.
- Логика `PinnedImageViewerWindow.xaml.cs`:
  - Конструктор принимает `byte[] pngBytes`, `Rect selectionRect` (экранные координаты).
  - Преобразование байт в `BitmapImage` с отвязкой потока (`CacheOption = BitmapCacheOption.OnLoad`).
  - Определение активного монитора через `System.Windows.Forms.Screen.FromRectangle(...)`.
  - Расчет стартовых размеров окна с учетом системных рамок и заголовка Windows, ограниченных $0.9 \times$ от рабочей области монитора (`WorkingArea`).
  - Расчет центрированных координат `Left` и `Top` с учетом каскадного смещения (+24 px для каждого уже открытого окна `PinnedImageViewerWindow`).
  - Установка локализованного заголовка окна с указанием ширины и высоты кадра в пикселях.

### 3.4. Оркестрация в `MainWindow`
- В `MainWindow.xaml.cs` в методе `StartOcrCapture` (в блоке настройки оверлея для скриншота):
  - Подписка на событие `overlay.PinRequested`.
  - Создание и отображение `PinnedImageViewerWindow` в потоке `Dispatcher`.
  - Сброс статуса трея в `TrayStatus.Idle`.
  - Логирование события через `Log.Information(...)`.
  - Восстановление дашборда при необходимости (`wasVisible`) и вызов `UpdateUiState()`.

## 4. Non-Functional Requirements & Code Style
- Соответствие руководству по стилю `conductor/code_styleguides/csharp.md` (отступы 2 пробела, скобки K&R).
- Покрытие тестами локализации в `LocalizationManagerTests` и хелпера позиционирования/каскадирования.
- Нулевые регрессии существующих сценариев сохранения скриншотов, копирования в буфер обмена и режима OCR.
- Работа только в RAM без утечек памяти: потоки `MemoryStream` освобождаются, `BitmapImage` замораживается (`Freeze()`).

## 5. Acceptance Criteria
1. Все модульные тесты решения успешно проходят: `dotnet test`.
2. В режиме аннотаций скриншота на панели инструментов присутствует кнопка `📌` перед кнопкой копирования `📋`.
3. При клике на `📌` оверлей закрывается, и открывается отдельное окно `PinnedImageViewerWindow` с захваченной областью и всеми нарисованными аннотациями.
4. Окно центрируется на том мониторе, где производился захват (не превышая 90% рабочей области).
5. При повторном закреплении нового фрагмента открывается второе окно с каскадным сдвигом (+24 px), оба окна независимы.
6. Окно отображается в панели задач Windows с иконкой приложения и доступно по `Alt+Tab`.
7. Никаких файлов не сохраняется на диске в папку скриншотов.
8. Буфер обмена Windows и история SQLite остаются нетронутыми.
9. Заголовок окна отображает локализованный текст и размеры изображения `(W × H)`.
10. Тултип кнопки `📌` корректно локализован на русском и английском языках.

## 6. Out of Scope
- Дополнительные кнопки редактирования/зума внутри окна `PinnedImageViewerWindow`.
- Закрепление поверх всех окон (`Topmost = true`).
- Сохранение состояния закрепленных окон между перезапусками приложения.
