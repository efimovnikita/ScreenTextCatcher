# Specification: Инструмент «Ручка» (Freehand Pen with Smoothing) и релиз v1.5.0

## 1. Overview
В режим аннотации снимка экрана (`AppMode.Screenshot` в `OverlayWindow`) добавляется векторный инструмент рисования свободной формы — **«Ручка»** (`Pen`). Пользователь может рисовать произвольные кривые, рукописные пометки, подчеркивания и контуры. Инструмент оснащен двухэтапным конвейером сглаживания (Ramer–Douglas–Peucker + Catmull–Rom to Cubic Bézier), предотвращающим накопление дубликатов точек и устраняющим дрожание руки при сохранении естественной формы штриха. В завершение трека осуществляется поднятие версии до 1.5.0 и выпуск релиза на GitHub (`v1.5.0`).

---

## 2. Architectural Decisions & UI/UX (ADR)

1. **Конвейер сглаживания (Two-Phase Smoothing Pipeline)**:
   - **Интерактивный сбор (`MouseMove`)**:
     - Точки курсора накапливаются в буфер `_currentPenPoints`.
     - Пространственный фильтр: точка добавляется только при дистанции $\ge 2.0\text{ px}$ от предыдущей (`MinPenPointDistance`), исключая дубликаты при паузах и медленном ведении мыши.
     - Превью в реальном времени отрисовывается через фигуру `Path` с ломаной линией без задержек и отставания от курсора.
   - **Пост-сглаживание (`MouseUp`)**:
     - Если суммарная длина траектории $< 3.0\text{ px}$, штрих удаляется (защита от случайных мисскликов).
     - **Этап 1 (Шумоподавление)**: Алгоритм Рамера — Дугласа — Пекера (Ramer–Douglas–Peucker) с порогом $\varepsilon = 2.5\text{ px}$ отсекает микроколебания и дрожание руки, сохраняя ключевые изгибы.
     - **Этап 2 (Сплайновая аппроксимация)**: Построение $C^1$-гладкой кривой Безье через сплайны Катмулла — Рома (Catmull–Rom to Cubic Bézier) с натяжением $0.5$.
     - Результирующая геометрия упаковывается в замороженную (`Freeze`) `PathGeometry`, заменяя превью.

2. **Визуальный стиль контура**:
   - Элемент: `System.Windows.Shapes.Path`.
   - Геометрия: `System.Windows.Media.PathGeometry`.
   - Цвет: `#FF1744` (`AnnotationGeometryHelper.AnnotationColor`).
   - Толщина: `3.0 px` (`AnnotationGeometryHelper.StrokeThickness`).
   - Окончания штриха: `PenLineCap.Round`.
   - Сочленения сегментов: `PenLineJoin.Round`.
   - Заливка: `Brushes.Transparent`.

3. **Интеграция с UI панели инструментов (Toolbar)**:
   - Кнопка `BtnToolPen` размещается в панели аннотаций сразу после кнопки инструмента «Линия» (`BtnToolLine`): `[▢ Рамка] [➔ Стрелка] [― Линия] [✏ Ручка]`.
   - Иконка инструмента: глиф `✏` (FontWeight="Bold", FontSize="16").
   - Локализованный тултип через ресурс `{DynamicResource Loc_AnnotateToolbarPen}`.
   - Подсветка кнопки активного инструмента и установка курсора `Cursors.Cross`.
   - Повторный клик по кнопке сбрасывает инструмент в `AnnotationTool.None` и возвращает стандартный курсор.

4. **UX взаимодействия, отмена и непрерывное рисование**:
   - Инструмент остается активным после завершения штриха, позволяя последовательно рисовать серию пометок.
   - Одиночные клики и микро-движения $< 3\text{ px}$ отсекаются, не загрязняя холст и историю.
   - Клавиша `Shift` не влияет на ручку (рисование всегда свободное).
   - Каждый штрих регистрируется в `_annotationHistory`, поддерживается отмена через кнопку тулбара `[↩]` и хоткей `Ctrl+Z`.
   - Корректный композитный рендеринг через `AnnotationExportHelper` в исходном высоком DPI при сохранении (`✓`, `Enter`), копировании в буфер (`📋`) и закреплении (`📌`).

5. **Локализация (i18n)**:
   - Ключ `Loc_AnnotateToolbarPen`:
     - RU: `"Ручка"`
     - EN: `"Pen"`

6. **Версионирование и публикация**:
   - Поднятие версии решения до `1.5.0` в `ScreenTextCatcher.csproj` и `ScreenTextCatcher.Core.csproj`.
   - Создание git-тега `v1.5.0` и публикация релиза через GitHub Actions.

## 3. Functional Requirements

### 3.1. Хелпер геометрии (`AnnotationGeometryHelper`)
- Константы:
  - `DefaultPenSmoothingEpsilon = 2.5`
  - `MinPenPointDistance = 2.0`
- Метод `SimplifyPoints(IReadOnlyList<Point> points, double epsilon = DefaultPenSmoothingEpsilon)`:
  - Реализация алгоритма Рамера — Дугласа — Пекера.
  - При количестве точек $\le 2$ возвращает исходный список.
- Метод `CreateSmoothPathGeometry(IReadOnlyList<Point> points)`:
  - Построение `PathGeometry` с `PathFigure`.
  - При 2 точках — прямой `LineSegment`.
  - При $\ge 3$ точках — цепочка кубических `BezierSegment` по формулам Катмулла — Рома с граничными виртуальными точками $P_{-1} = 2P_0 - P_1$ и $P_{n+1} = 2P_n - P_{n-1}$.
  - Вызов `Freeze()` для оптимизации производительности.
- Фабрика `CreatePenPath(IReadOnlyList<Point>? initialPoints = null)`:
  - Создает `System.Windows.Shapes.Path` со стилем `#FF1744`, толщиной `3.0`, `StrokeStartLineCap = StrokeEndLineCap = PenLineCap.Round`, `StrokeLineJoin = PenLineJoin.Round`.
- Метод `UpdatePenPreview(Path path, IReadOnlyList<Point> points)`:
  - Создает быструю ломаную линию через `PolyLineSegment` в `PathGeometry`.
- Метод `FinalizePenStroke(Path path, IReadOnlyList<Point> points, double epsilon = DefaultPenSmoothingEpsilon)`:
  - Выполняет `SimplifyPoints` и заменяет геометрию `path.Data` на `CreateSmoothPathGeometry`.

### 3.2. Локализация (`LocalizationManager`)
- Регистрация ключа `Loc_AnnotateToolbarPen` в словарях русской и английской локализаций.

### 3.3. Разметка интерфейса (`OverlayWindow.xaml`)
- Добавление кнопки `BtnToolPen` в стек инструментов аннотации с тултипом и обработчиком `OnToolPenClick`.

### 3.4. Машина состояний оверлея (`OverlayWindow.xaml.cs`)
- Расширение перечисления `AnnotationTool` значением `Pen`.
- Буфер точек `_currentPenPoints`.
- Обработчики клика кнопки и переключения состояния курсора/подсветки.
- Обработка `OnCanvasMouseDown`, `OnCanvasMouseMove`, `OnCanvasMouseUp` для инструмента `Pen`.

## 4. Non-Functional Requirements & Code Style
- Строгое соблюдение соглашений `conductor/code_styleguides/csharp.md` (2 пробела отступ, K&R стиль фигурных скобок).
- Высокое покрытие модульными тестами вспомогательной математики (`AnnotationGeometryTests.cs`).
- Отсутствие задержек при отрисовке превью на экранах любой частоты обновления (60–144+ Гц).
- Защита от мутаций и утечек памяти (заморозка `PathGeometry.Freeze()`, своевременная очистка буферов точек).

## 5. Acceptance Criteria
1. Все существующие и новые модульные тесты проходят успешно (`dotnet test`).
2. В панели аннотаций отображается кнопка `✏` с корректными тултипами на русском и английском языках.
3. При выборе инструмента курсор меняется на перекрестие, кнопка подсвечивается; повторный клик отключает режим.
4. Протяжка мыши рисует плавную непрерывную линию в реальном времени.
5. При отпускании мыши контур сглаживается без микро-колебаний и угловатостей.
6. Одиночные клики и штрихи $< 3\text{ px}$ отбрасываются и не попадают в историю Undo.
7. Штрихи отменяются через `[↩]` и `Ctrl+Z` по одному в порядке, обратном рисованию.
8. Экспорт через сохранение в файл (`✓`), копирование (`📋`) и закрепление (`📌`) содержит векторный контур в исходном качестве и высоком DPI.
9. Версия приложения обновлена до 1.5.0, создан git-тег `v1.5.0` и собран релизный архив в GitHub Actions.

## 6. Out of Scope
- Меню выбора цвета или толщины пера.
- Поддержка нажима пера графического планшета (Stylus/Pressure).
- Клавиатурный хоткей активации ручки на оверлее.
- Автоматическое распознавание геометрических примитивов (Auto-Shape Recognition).
